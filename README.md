## 🚀 Featured Projects

### 📝 Notes 101 — Minimal Dark Note-Taking Studio

A minimal, dark-themed note-taking web workspace featuring A4 paper desk layouts, dynamic pagination, freehand canvas drawing layer, color spectrum pickers, and real-time Firebase cloud sync.

- 🔓 **Open Source**: 100% free, open-source, and ad-free.
- ✂️ **A4 Pagination**: Dynamic page-splitting logic as you type.
- 🔤 **100+ Google Fonts**: Switch font typography directly from the sidebar inspector.
- 🖌️ **Freehand Sketch Layer**: Draw directly over notes with fountain pen, pencil, and art brush.
- 📄 **1-Click PDF Export**: Download formatted note pages as PDF documents.
